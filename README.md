# Memory Card Game

## Description
This is a simple memory card game written in Python.
The player selects two cards each turn to find matching pairs.

## How to Run
1. Open terminal
2. Type:
   py memory_game.py

## Features
- Random card shuffle
- Match checking
- Move counter
- Simple terminal interface
